## 確認した接続

最終確認：`npm run build`、`npm run typecheck`、Node 24でのVitest（25ファイル・255件）が成功。ブラウザ確認用の生成物もリポジトリ外へ移し、一時ルートを含まない状態で確認した。

- lib/board-validation.ts は lib/validation.ts の validateRoom を呼ぶだけ。検証エンジンのアルゴリズムやマスターには変更なし。
- ボードと負担画面はともにuseRoomValidationを使用。結果と入力revisionを組にして扱い、再取得中や検証中に古い結果を現在の合格・色づけへ流用しない。
- ボードの色づけはValidationResult.gapsの時刻範囲を表示するだけ。空白をplacementsから独自に再計算しない。
- 対応不可の家族配置が空白セルを覆う場合も青い縁と「支援の空白」ラベルが見える。表示がドラッグやフォーム操作を妨げないようpointer-eventsを無効にした。
- 負担ビューはmemberHours・overloads・selfPayBreakdownを表示する。家族別の費用配分、制度の単位・費用計算、代替案は追加していない。
